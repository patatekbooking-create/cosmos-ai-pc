# Cosmos AI pour Windows

**[⬇ Télécharger Cosmos AI pour Windows (Cosmos-AI.exe)](https://github.com/patatekbooking-create/cosmos-ai-pc/raw/main/Cosmos-AI.exe)**

1. Télécharge `Cosmos-AI.exe` et ouvre-le. Si Windows affiche « Windows a protégé votre ordinateur », clique sur **Informations complémentaires** puis **Exécuter quand même** (l'application n'est pas encore signée).
2. Cosmos AI s'ouvre dans sa propre fenêtre : connecte-toi avec ton compte Cosmos.
3. Pour l'avoir toujours sous la main : clic droit sur l'icône dans la barre des tâches → **Épingler à la barre des tâches**.

L'application est reliée au serveur Cosmos AI : les nouveautés arrivent toutes seules, sans réinstaller.
Accès sur validation : un nouveau compte attend l'accord de l'administrateur (Toxic Twins).
